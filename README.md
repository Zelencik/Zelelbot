# ZelenBot AI chat update

1. Replace `app.py` and `requirements.txt` in the GitHub repository with these versions.
2. Streamlit Cloud will redeploy automatically.
3. Without an API key, the chat works in basic mode using saved notes and simple replies.
4. To enable full AI, an adult helper should configure `OPENAI_API_KEY` in the app's Streamlit Secrets. Never put the key in GitHub, source code, or a chat message. API usage may cost money.
5. `knowledge.json` can remain as it is.

The app is a knowledge/chat helper, not a bot that controls Roblox.
